# Twins Scheduler Closure

This repository studies a bounded safety-observation separation between a
phase-specific scheduler grammar and a type-uniform directed-edge grammar for
finite certificate-driven locking models.  The main claim is a bounded
rule-level result, not a production CometBFT vulnerability or full client
conformance claim.

The canonical source is under `src/`, the primary mature proof is under
`formal/lean/`, the manuscript is under `manuscript/`, and immutable acquisition
material is separated into `provenance/` and `archive/stages/`.

The complete one-command reproduction interface will be `./reproduce.sh`.
