# Gate 6′ fuller event-loop specification

## Objective

Validate the phase-coupled scheduler boundary in a fuller local consensus event
loop rather than in a terminal-state formula or phase-barrier-only kernel.

## Participants and quorum

- logical leader: `B`;
- correct replicas: `H1`, `P`, `H3`;
- quorum: `3` of `4` logical validator identities;
- round 0 proposes value `0` to `H1` and pivot `P`;
- round 1 proposes conflicting value `1` to `P` and `H3`.

The leader contributes one stable logical vote in each vote phase. Duplicate
vote keys do not add voting power.

## Event phases

```text
PROPOSAL -> PREVOTE -> POLKA -> PRECOMMIT -> COMMIT
```

Messages are dynamically generated by handlers and placed in an explicit event
queue. A POLKA forms after three unique prevotes; COMMIT evidence forms after
three unique precommits. Correct replicas maintain persistent locks and
irreversible decisions.

## Controlled mutation

`MISSING_LOCK_UPDATE` suppresses the persistent lock assignment when a replica
accepts a POLKA. No other transition changes.

## Scheduler policies

Only the round-0 edge `B -> P` is controlled.

- `G_T_TYPE_SPECIFIC`: proposal and POLKA pass; COMMIT is withheld.
- `G_D_ROUND0_EDGE_OFF`: the edge is absent for every phase.
- `G_D_ROUND0_EDGE_ON`: the edge is present for every phase.

All other edges are open.

## Predicted outcomes

| Mutation | Phase-specific | Directed off | Directed on |
|---|---|---|---|
| Baseline | safe: pivot locks 0 | safe: round 0 lacks quorum | safe: pivot decides 0 |
| Missing lock update | unsafe: decisions 0 and 1 | safe: round 0 lacks quorum | safe: terminal evidence makes pivot decide 0 |

## Independent implementations

- Go: `implementation_fixture/full_event_loop`;
- Python: `src/schedcheck/gate6/event_loop.py`.

The FIFO implementations agree exactly on all six canonical terminal results.
The Python implementation additionally checks FIFO, LIFO, and 256 seeded random
queue-selection orders. These variations preserve causal generation and do not
change any safety classification.

## Limits

This is an isolated deterministic fixture informed by the pinned protocol
semantics examined in Gate 5′. It is not a fork of the complete CometBFT event
loop, does not reproduce networking or pacemaker timing, and does not establish
a production vulnerability.
