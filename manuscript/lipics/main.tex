{\LARGE\bfseries Certified Minimum-Cost Scheduler Refinement for Stateful BFT Testing\par}
\vspace{12mm}
\begin{minipage}{0.88\textwidth}
\textbf{Abstract.}
Sharing one admission decision across message phases can remove a BFT agreement counterexample. We formulate the least-cost phase distinctions needed to recover an unsafe execution over arbitrary control-labelled protocol transition systems. A static policy must preserve each fine key's answer across repeated queries; the least refinement of a consistent trace is exactly its required and mixed coarse fibres. Exact finite-state search returns a witness and an independently checked closed-sublevel certificate, without assuming independent pivots or additive quorum contributions. A labelled simulation transfers abstract lower bounds to a detailed model; a concrete witness of matching cost establishes its optimum. An invariant-guided abstraction procedure eliminates entire spurious policies and makes finite progress. A seven-validator study has six coupled control fibres, 48,201 states and 55,283 transitions. Refinement rejects nine spurious policies before a 562-state quotient and guarded witness certify a minimum of two splits. Baselines, dependency ablations and complete-policy checks support this bounded result; total refinement work exceeds direct search. Independent policy oracles and a Set Cover reduction validate the general solver, while a repair-graph specialization retains weighted quota synthesis up to 48 pivots. Lean mechanizes the policy, certificate, simulation and invariant-refinement principles. Separate tests execute unchanged CometBFT code with native signatures. The executable optimum is relative to a complete supplied model and static control interface; applying it to arbitrary client code requires transition and observation coverage.
\end{minipage}
