{\LARGE\bfseries Phase Erasure in BFT Testing: Repair Frontiers and Irreversible Votes\par}
\vspace{12mm}
\begin{minipage}{0.88\textwidth}
\textbf{Abstract.}
Aggregating protocol phases into one network admission bit can remove a finite agreement counterexample by delivering evidence that prevents an indispensable vote. We identify the correct boundary: repair must precede vote issuance, because later repair cannot retract signed output. For an independent-pivot certificate schema with arbitrary finite opportunity orders, a derived repair graph characterizes jointly reusable contributors. With $k$ unit-weight pivots and quorum deficits $d_0,d_1$, coarse unsafe reachability is equivalent to $\max(d_0,d_1)\le k$ and $d_0+d_1\le k+\alpha(H)$, where $\alpha(H)$ is the maximum induced-acyclic cardinality. We derive the exact minimum phase-splitting budget and a weighted extension. A complete four-validator Tendermint-style trace includes actual local quorums, nil votes, guarded timeouts, and one omitted round-0 lock update; a late-repair control retains conflicting decisions even with FIFO-compatible vote delivery through gossip. Exhaustive finite checks and scoped Lean proofs support the result. The graph argument uses classical order-reversal theory; the application concerns explicitly declared scheduler contracts, not universal framework incompleteness or production-client conformance.
\end{minipage}
