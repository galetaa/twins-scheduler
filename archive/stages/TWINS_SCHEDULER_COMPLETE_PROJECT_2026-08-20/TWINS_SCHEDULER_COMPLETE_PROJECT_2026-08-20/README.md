# TWINS Scheduler complete project bundle

**Bundle date:** 20 August 2026  
**Bundle root:** `TWINS_SCHEDULER_COMPLETE_PROJECT_2026-08-20`

This archive consolidates every project artifact physically available in the active workspace, including original research inputs, the initial specification package, all Gate archives from the original Gate 0–3 line through Gate 8′, standalone reports and result exports, code, formal specifications, proof artifacts, generated figures, manuscripts, PDF review material, and reproducibility scripts.

## Layout

- `00_inputs/` — original brief, first research report, and independent topic audit.
- `01_initial_specification/` — the first full research specification and its eight standalone Markdown files.
- `02_top_level_exports/` — standalone reports, ledgers, matrices, figures, PDFs, and checksum files exported during the project.
- `03_workspace_directories/` — directory trees that were directly present in the workspace.
- `04_original_stage_archives/` — byte-preserved historical ZIP archives and their checksum companions.
- `05_expanded_stage_archives/` — extracted content of every available historical project ZIP.
- `06_render_evidence/` — retained PDF-render inspection evidence.
- `07_provenance/` — workspace inventory, missing-artifact disclosure, and the proof-audit report reconstructed from the user's pasted text.
- `MANIFEST.csv` — path, size, SHA-256, and file type for every regular file in this bundle.
- `SHA256SUMS` — standard checksum list for all regular files except the checksum list itself.
