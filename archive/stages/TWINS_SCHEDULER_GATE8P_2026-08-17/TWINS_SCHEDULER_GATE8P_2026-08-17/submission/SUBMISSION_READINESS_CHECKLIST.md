# Submission Readiness Checklist

## Scientific

- [x] Central question frozen at property-preserving scheduler closure.
- [x] T1/T2/T3/T6 statements scoped and linked to evidence.
- [x] Strong and weak claims separated from nonclaims.
- [x] Executable baseline, mutations, controls, and counterfactuals documented.
- [x] Negative result remains scientifically interpretable.
- [ ] Independent proof review or successful kernel-checked proof-assistant build completed.
- [ ] Natural protocol assumption map reviewed by a distributed-systems specialist.
- [ ] Prior-art and engineering search refreshed on the actual submission date.

## Manuscript

- [x] Full anonymous English manuscript drafted.
- [x] Separate cover page and abstract included in the working PDF.
- [x] Sentence-level claim-to-evidence audit completed.
- [x] Reviewer-objection matrix completed.
- [x] AI-use disclosure drafted.
- [ ] Converted to official current LIPIcs A4 template.
- [ ] Final 15-page main-text budget verified under LIPIcs.
- [ ] Author metadata, affiliations, ORCIDs, funding, and best-student eligibility supplied.
- [ ] Anonymous metadata and self-citation audit passed.

## Artifact

- [x] Gate 7 core evidence reproduces offline.
- [x] Legacy exact-kernel archive and checksum included.
- [x] Gate 8 script validates manuscript, claims, and inherited evidence.
- [x] Source and result hashes generated.
- [ ] Container image or equivalent venue-compliant environment produced.
- [ ] Public persistent DOI assigned.
- [ ] External clean-host reproduction by a person not involved in artifact creation recorded.

## Final decision rule

Submission is permitted only when all unchecked items in the **Scientific** section and both LIPIcs-format items are closed. A DOI/container may follow the selected venue’s artifact timetable, but the manuscript must not imply they already exist.
