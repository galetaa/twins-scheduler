# SchedCheck: Gate 0′–3′ scheduler-grammar pilot

`SchedCheck` is an exact, finite, dependency-free checker for comparing safety-observation languages generated by four network scheduler grammars:

```text
G_P_PARTITION
  ⊆ G_D_DIRECTED_VIEW
  ⊆ G_T_TYPE_SPECIFIC
  ⊆ G_M_PER_MESSAGE
```

The artifact is a blocking pilot for a narrowed research question about safety-preserving completeness of view-partition fault schedules. It does not claim a vulnerability in HotStuff or any production client.

## Main result

Within the declared finite deterministic protocol class, all inclusions hold and every adjacent inclusion is strict on agreement-violating observations:

- `ECHO_GATE` separates partitions from directed view graphs;
- `TYPE_SPLIT` separates directed graphs from type-specific graphs;
- `INSTANCE_ORDER` separates type-specific graphs from per-message schedules;
- `TWIN_BRANCH_CONTROL` is a positive control already found by partitions.

The overall decision is **ТРЕБУЕТ СУЖЕНИЯ**: proceed only toward a closure-preservation theorem or natural BFT separation, not toward a large new fuzzer.

## Scope limits

The model has one logical view, no real time, no cross-view late delivery, no replay, no payload mutation, and no liveness property. Diagnostic protocols are intentionally small and unsafe. Production relevance must be established in Gate 4′.
