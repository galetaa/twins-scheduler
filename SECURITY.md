# Security policy

This is a bounded research and verification artifact. It is not designed for
mainnet exploitation, live validator fault injection, denial of service, key
handling, or attacks on production CometBFT deployments. Test only isolated
local models and systems for which you have authorization.

Report suspected safety mistakes, dependency-integrity problems, leaked
identity metadata, or secrets privately to the maintainers of the distribution
channel from which this artifact was obtained. Do not publish operational
exploit instructions or production target data in an issue.
