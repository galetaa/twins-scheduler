# Architecture

The active artifact has four assurance layers. Python and Go enumerate the
same finite scheduler domain and serialize canonical terminal observations.
Independent Python checks and Z3 obligations exercise the mechanism and its
damaged controls. A project-local certificate kernel checks explicit proof
objects. Lean is the primary mature prover and states the general theorems.

The manuscript consumes only active sources and committed reference evidence.
`reproduce.sh` redirects generated files to an isolated tree and compares them
with the canonical tree. Historical snapshots and raw inputs are evidence of
lineage only and are fenced from Go, Python, Lean, and paper builds.

The bounded protocol bridge explicitly models E, R, C0, C1, a shared directed
edge with distinct phases, correct and `MISSING_LOCK_UPDATE` transitions, and
certificate-to-decision observations. This component refines the structural
quorum-pivot criterion; it does not claim production-client conformance.
